The first build will be grey chrome, system blue selection, a red badge that means nothing in particular, and a black terminal with green text. Every element asks for attention equally, so nothing gets it.

Loam fixes that with three moves. Surfaces recede by depth, so the terminal reads as the work. Colour means state, and there are only two states worth a colour. Change is visible and reversible, so Claude can edit the plot without you worrying about it.

II · SURFACES

A soil profile, read top down.

Each surface is a horizon. The closer a surface is to the work, the deeper it sits. Hover a layer.

III · ATTENTION

Two signals. Never three.

Hue tells them apart, and so does shape, for anyone who cannot see the hue.

Needs you

A session waits on your answer in the middle of a turn: a permission prompt or a question. A filled dot. On arrival, a halo grows three times, then stops. It clears only when the session moves on.

needs-youneeds-you-washduration-halo 1600ms

Done, unread

A session finished a turn that you have not seen. A hollow ring, never filled, never animated. It clears the moment you look at the pane.

done-unreaddone-unread-wash1.5px stroke
A running session shows nothing. An idle one shows nothing. Errors appear in the pane as words, not as a third dot. If everything has a light on, no light means anything.

VII · LANDING IT

Four steps into the Swift app.

In order, because each one feeds the next.

  1. Generate LoamTheme.swift from tokens.json

    One NSColor per colour token with a dynamic provider for Night and Day, plus the spacing, radius and duration constants. A Go test in core/ or a Swift test checks that the file matches the JSON.

  2. Ship the Ghostty themes loam-night and loam-day

    Background bedrock, foreground ink, the 16 ansi-* colours, cursor and selection. Ticket 26 loads them by default and follows the system appearance.

  3. Build the attention dot and plot row first

    They carry the two signals, and tickets 28 and 32 need them. Then the change row and link row for tickets 35 and 36, then the switcher for ticket 38.

  4. Add motion last, behind Reduce Motion

    Every transition uses ease-settle or ease-lift from the theme. The halo is the only loop, and it stops when the pane gets focus.
